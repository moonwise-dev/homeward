## Data Model

### `/brief`

What Homeward learned about the household, written with update_brief: an object of items by ID. Seeded by `update_brief`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/brief/<id>` | object read by Homeward components | One item: { id, kind, text, source, words }. Bind it whole to a Fact. |

### `/affordability`

What compute_affordability found for this household, from sample rules. Seeded by `compute_affordability`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/affordability/price` | money object { "minorUnits": integer, "currency": ISO 4217 code } | The price assessed |
| `/affordability/maxPrice` | money object { "minorUnits": integer, "currency": ISO 4217 code } | The highest price the savings and rules allow |
| `/affordability/maxLoan` | money object { "minorUnits": integer, "currency": ISO 4217 code } | The largest loan the rules allow at the price |
| `/affordability/binding` | object read by Homeward components | The rule that limits the loan; bind it to a RuleNote |
| `/affordability/checks` | object read by Homeward components | Every rule checked, in order; bind one to a RuleNote as /affordability/checks/<n> |

### `/homes`

The sample homes search_homes found, each priced for the household: an object of homes by ID. Seeded by `search_homes`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/homes/<id>` | object read by Homeward components | One home: { listing, cost }. Bind it whole to a HomeCard. |

### `/reads`

Sample homes read_listings read for the household's needs: an object by home ID. Seeded by `read_listings`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/reads/<id>` | object read by Homeward components | One home: { homeName, description, readings }. Bind it whole to a ListingQuote. |

### `/swipe`

The deck search_homes dealt with deal: sample homes that differ. Seeded by `search_homes`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/swipe/homes` | object read by Homeward components | The deck in order, each { listing, cost }. Bind it to a HomeSwipe. |

### `/week`

The buyer's week measured with measure_week: an object by starting point, a sample home or a place ID. Seeded by `measure_week`.

| Path | Value | Meaning |
| --- | --- | --- |

| `/week/<from>/trips/<n>` | object read by Homeward components | One trip: { placeName, perWeek, mode, minutes, meters }. Bind it to a RouteSummary. |

### `/rentSplit`

A home's rent and bills split between the people sharing it, by each rule split_rent could work out. Seeded by `split_rent`.

| Path | Value | Meaning |
| --- | --- | --- |
| `/rentSplit/rent` | object read by Homeward components | The rent a month: the buyer's or an estimate from the area, with its source |

| `/rentSplit/splits` | object read by Homeward components | Each rule's parts per person; bind the whole slice to a RentSplit |
