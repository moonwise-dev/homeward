### LocationPicker

Chooses a market or a country and writes its ISO 3166 code. Use mode market for where the buyer is buying, with the select_market action; use mode country for citizenship and tax residence.

### MoneyInput

An amount field that writes a money object to the bound path. Use it for incomes, savings, debts, and fees; never write amounts yourself.

### HouseholdInput

Asks who lives in the home: how many adults and the age of each child, with a one-tap answer for no children. Use it for the household fact, bound to /profile/adults and /profile/childAges.

### AmountSlider

A money slider between bounds computed from the rules, showing the value and its share of another amount. Use it for the down payment, bound to /derived/downPaymentBounds.

### MarketSnapshotCard

The selected market at a glance for this buyer: its name, whether Homeward has curated rules there, the kinds of rule that apply, and the reference rate behind the payment. In an uncovered market it says so and names the markets Homeward covers. Draw it when the market is new to the buyer.

### AffordabilitySummary

The maximum loan, the rule that limits it, and headroom against the current scenario, computed from the rules. Show it after the profile is committed; never restate its figures in text.

### PaymentBreakdown

The first monthly payment split into interest and amortization, with fees, the total, and in Sweden the cost after the interest deduction.

### PurchaseCostsTable

Every upfront cost this buyer owes on the day, the total, and the cash needed with the down payment. A charge that is partly refunded shows what comes back and what earns it.

### StressTestChart

Monthly cost from today's rate up past the rate the lender tests, against the most this buyer can pay each month, with today and the stress rate marked.

### EligibilityChecklist

Every lending rule this buyer is measured against, each passing, warning, or failing, with what would settle it and what facts are still missing.

## Data Model

### `/selection`

What the buyer is picking before it is saved.

| Path | Value | Meaning |
| --- | --- | --- |
| `/selection/marketId` | ISO 3166 code of a country or subdivision, such as SE or PT-30 | The market picked in a LocationPicker in market mode. |
| `/selection/candidates` | object read by Homeward components | Markets that match the place the buyer named, with coverage. |

### `/profile`

The buyer profile. Inputs write one field each; insights bind the whole slice.

| Path | Value | Meaning |
| --- | --- | --- |
| `/profile/citizenship` | ISO 3166-1 alpha-2 country code | Country of citizenship. |
| `/profile/taxResidence` | ISO 3166-1 alpha-2 country code | Country the buyer pays tax in. |
| `/profile/formerResident` | boolean | Ever tax resident in the target market. |
| `/profile/residencyIntent` | one of stay, becomeResident | Whether the buyer plans to become tax resident in the target market. |
| `/profile/use` | one of primary, secondary, investment | How the buyer will use the home. |
| `/profile/firstTime` | boolean | Buying a home for the first time. |
| `/profile/employment` | one of employed, selfEmployed, retired | How the main borrower earns an income. |
| `/profile/age` | integer | Age of the oldest borrower. |
| `/profile/netMonthlyIncome` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Household income per month after tax, in the currency it is paid in. |
| `/profile/grossMonthlyIncome` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Household income per month before tax, in the currency it is paid in. |
| `/profile/monthlyDebtPayments` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Payments on existing loans and credit per month. |
| `/profile/savings` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Cash available for the purchase. |
| `/profile/borrowers` | integer | People named on the loan. |
| `/profile/adults` | integer | Adults in the household. |
| `/profile/childAges` | list of integers | Age of each child at home. |

### `/scenario`

The purchase being tried. Inputs write one field each; insights bind the whole slice.

| Path | Value | Meaning |
| --- | --- | --- |
| `/scenario/price` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Price of the home. |
| `/scenario/downPayment` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Cash the buyer puts down. |
| `/scenario/termYears` | integer | Loan term in years. |
| `/scenario/loanTypeId` | string | A loan type id from the market, such as variable-3m. |
| `/scenario/rateSpreadPpm` | integer parts per million; 10000 is 1% | Lender's margin over the reference rate. |
| `/scenario/rateShockPpm` | integer parts per million; 10000 is 1% | Rate rise to test against. |
| `/scenario/associationFee` | money object { "minorUnits": integer, "currency": ISO 4217 code } | Monthly fee to the housing association. |

### `/market`

The rules of the selected market that apply to this buyer, read-only. Insights bind the whole slice.

| Path | Value | Meaning |
| --- | --- | --- |
| `/market/id` | ISO 3166 code of a country or subdivision, such as SE or PT-30 | The market. |
| `/market/name` | string | Market name in English. |
| `/market/coverage` | one of curated, uncovered | Whether Homeward has curated rules here. An uncovered market carries only the market, its name, and this field. |
| `/market/currency` | ISO 4217 currency code | Currency of prices and loans; bind it as the currency of money inputs. |

### `/derived`

Figures the server computed for the scenario, read-only.

| Path | Value | Meaning |
| --- | --- | --- |
| `/derived/affordability` | object read by Homeward components | Maximum loan, the binding limit, and each check. |
| `/derived/downPaymentBounds` | { "min", "max", "step" }, each a money object | Down payment range the rules allow; bind it as AmountSlider bounds. |
| `/derived/payment` | object read by Homeward components | First monthly interest, amortization, and total. |
